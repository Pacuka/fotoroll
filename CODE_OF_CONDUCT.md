# Code of conduct

Fotoroll follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, respectful and constructive; focus on what is best for the project and its
users; no harassment, insults, personal attacks or publishing others' private information. This
applies in issues, pull requests, discussions and anywhere you represent the project.

## Enforcement

Report unacceptable behaviour privately to the maintainer
([@Pacuka](https://github.com/Pacuka)), for example through a
[private security report](https://github.com/Pacuka/fotoroll/security/advisories/new) if it needs to
stay confidential. All reports are reviewed and kept confidential. The maintainer may remove,
edit or reject comments, commits, issues and other contributions that don't follow this code, and may
temporarily or permanently ban contributors, following the Contributor Covenant's enforcement
guidelines.
